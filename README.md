# Bemplayer

An Emby client for Android TV, built for a remote control rather than a touchscreen.

No release has been published yet. This page is replaced automatically when the first
version ships, and will then carry the downloads, checksums and install instructions.

Releases are built from a private source repository. This repository holds the published
builds, this page and `update.json`, which is the file the app polls to discover new
versions.
